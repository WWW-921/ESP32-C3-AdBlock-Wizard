# 1.0.0-preview

提供五步中文向导：准备、刷写、配网、路由器、验收。

- 仅接受 ESP32-C3 / 4MB；先备份原 Flash，再写入并校验通用镜像。
- 预置 119631 条规则，每台设备独立生成热点、网页及 OTA 密码。
- 支持兼容小米路由器的 DHCP IP 绑定与 DNS 预览、确认应用、备份、回读和恢复；其他路由器使用手动引导。
- 验收同时检查设备 DNS 和 Windows 默认解析路径；不能可靠过滤 YouTube 视频广告。
- 12 项自动测试及原生引擎联调通过；硬件和 UI 测试范围详见 validation.md。

原始个人设备配置、原始 Flash 备份、私密凭据和构建缓存不在仓库中。项目保留上游许可证和来源，新增源码按 GPL-2.0-or-later 提供。
