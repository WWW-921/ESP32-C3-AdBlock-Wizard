# ESP32 广告过滤完整向导

已获用户确认：完整向导，Windows 中文界面，Delphi/Object Pascal 源码。

方案：原生 Win32 界面，配套冻结的 Python 操作引擎，通用 ESP32-C3 固件。界面启动时从资源释放组件，使用请求文件和结果文件通信，耗时操作放在工作线程。不要求最终用户安装 Python 或 PlatformIO。

流程：环境检查和串口识别；验证 ESP32-C3/4MB，完整备份后刷写；通过设备配网热点由用户输入 Wi-Fi；读取串口打印的每设备独立管理密码；发现设备，检查规则和 DNS；小米路由器登录、备份配置、预览 DHCP 绑定及 DNS，用户明确确认后保存；恢复原配置；重新获取租约与系统 DNS 验收。其它路由器显示精确填写值和手动引导。

设备配网不内置家庭 Wi-Fi；随机密码保存在设备 NVS，只向 USB 串口打印。日志与诊断报告不包含凭据；操作引擎不记录完整请求。串口关闭、刷写失败、型号不符、规则为空、DNS 绕过均显示失败，不能显示全网成功。刷写前读取并验证芯片与 Flash，备份成功才写；不会自动改写当前已安装的设备。

小米配置仅处理私有地址网关，登录凭据仅存进程内；从实际页面取得登录算法及接口，配置前检查网段和 ESP32 实测。保存旧 DHCP 和绑定信息到本机备份。不得关闭 DHCP、改变网段或覆盖其它绑定。恢复仅还原工具修改的项目。

界面页签：准备、刷写、配网、路由器、验收；右侧结果和日志。所有写入均有确认；当前家庭设备只做只读测试。交付单个主 EXE、源码 ZIP、使用说明和验证报告。编译环境如没有 Embarcadero，则使用 FPC Delphi 模式并明确标注，不能声称由 dcc 编译。
